# mag-site

Design portfolio for Magdalena Wilson. Plain static HTML/CSS, no build step, so it works on GitHub Pages as is.

- `index.html`: home page (currently just the header)
- `assets/site.css`: shared styles

`Portfolio Content/` holds the original source files and is git-ignored (about 1.2 GB).

Preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
